# Обновление

Выполняйте команды из папки установки с файлами `.env` и `compose.yaml`.

## Перед обновлением

Сохраните существующий том БД, `POSTGRES_PASSWORD`, `JWT_SIGNING_KEY` и `ENCRYPTION_KEY`. Перед миграциями сделайте резервную копию PostgreSQL и `.env`. Не удаляйте тома при обновлении.

## Скачайте образы

```sh
sudo docker compose pull
```

## Сначала обновите backend

Backend автоматически применяет миграции при запуске.

```sh
sudo docker compose up -d --wait backend
```

## Обновите панель

```sh
sudo docker compose up -d --wait frontend
```

## Проверьте результат

```sh
sudo docker compose ps
```

```sh
sudo docker compose logs --tail=50 backend
```

В конфигурации установки используется `latest`. Перед обновлением прочитайте [описание релизов](https://github.com/dementia-panel/backend/releases).

## Уже установленные ноды

Нодам, установленным до v0.7.1, нужен один переход по SSH. В панели откройте **Ноды**, выберите **Обновить ноду** и введите SSH-данные VPS. Пароль не сохраняется. Обновление сохраняет VPN-ключи и конфигурацию сервера и устанавливает таймер, который проверяет релизы ноды каждые 12 часов. После восстановления связи карточка покажет версию агента.

Чтобы получить новые параметры маскирующих пакетов, скачайте клиентский профиль заново. Уже импортированные профили не изменяются удалённо и продолжают работать с прежними параметрами до повторного импорта.
