# Ноды

Подключите VPS — backend установит ноду через SSH.

## Подготовьте сервер

- Ubuntu или Debian, root либо пользователь с правами sudo.
- Доступный `/dev/net/tun` на VPS.
- Исходящий HTTPS-доступ к GitHub и адресу панели `PUBLIC_URL`.
- Входящий UDP на выбранном VPN-порту, по умолчанию `51820`.

## Добавьте ноду

Откройте **Ноды → Подключить ноду**. Укажите имя, IP-адрес VPS, SSH-порт, логин и пароль. Выбранное имя применяется при установке.

Установщик проверит ОС, установит Docker и развернёт AmneziaWG. Установка может занимать до 15 минут. Этапы и ошибки отображаются в карточке ноды.

## Управление нодой

| Действие | Результат |
| --- | --- |
| Переименовать | Меняет отображаемое название. |
| Приостановить | Отключает VPN-доступ после синхронизации ноды. |
| Проверить связь | Ожидает новый отчёт агента; это не ICMP ping. |
| Перезапустить | Передаёт агенту запрос перезапуска. |
| Удалить из панели | Удаляет записи и назначения без подключения по SSH. |
| Удалить и очистить VPS | Подключается через SSH, останавливает контейнеры и удаляет установленные файлы ноды. |

## Повторная установка

Прочитайте ошибку в карточке ноды. Если VPS переустановлен и SSH-ключ изменился, явно разрешите новый ключ при повторной установке. По умолчанию известный ключ не заменяется автоматически.

Журнал установщика описан в разделе [Решение проблем](./troubleshooting).
