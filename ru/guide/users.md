# Пользователи и устройства

## Планы подписок

Создайте план из серверов, которые должны быть доступны вместе. План содержит серверы; состояние и срок действия задаются для выданного пользователю доступа.

## Пользователи

Создайте пользователя с именем и необязательным Telegram ID. В его карточке назначьте план подписки, включите или приостановите доступ и укажите срок действия либо оставьте его бессрочным.

В API пользователя можно указать по UUID или положительному Telegram ID. Telegram ID должен однозначно определять пользователя.

## Устройства

Добавляйте именованные устройства в карточке пользователя. Каждое получает отдельные ключи на назначенных серверах и свою ссылку подписки. Новое устройство не заменяет существующие.

| Настройка | Поведение |
| --- | --- |
| Лимит по умолчанию | Применяется к новым пользователям. |
| Лимит пользователя | Меняет ограничение конкретного пользователя; null — без лимита. |
| Уменьшение лимита | Сохраняет выданные устройства и запрещает выдачу новых сверх лимита. |
| Переименование | Сохраняет ключи устройства. |
| Удаление | Удаляет ссылку и ключи; отзыв применяется после синхронизации нод. |

Количество устройств — это **число выданных наборов ключей**, а не автоматически определённых физических аппаратов. Импорт того же профиля на другой телефон не создаёт новую запись.

## Профили подключения

Для каждого сервера доступны отдельные `.conf`, `.vpn`, ключ `vpn://` и QR-код для выбранного приложения. WireGuard `.conf` не является многосерверной подпиской. Страница подписки помогает выбрать сервер и приложение.

## UUID пользователя через API

`POST /api/admin/users` принимает необязательное поле `id` с UUID пользователя. Если поле отсутствует или равно `null`, UUID генерируется автоматически. Существующий UUID возвращает `409`: предыдущий пользователь не изменяется. Это работает при создании как с `plan_id`, так и без него.

[Создать пользователя через API →](/ru/api/users#создать-пользователя)

## Дата и время окончания подписки

При создании пользователя выберите подписку и снимите **Без ограничения срока**, чтобы указать точные дату и время окончания. Пользователь и срок подписки сохраняются вместе. В карточке пользователя можно изменить этот срок. Время выбирается в часовом поясе браузера и передаётся в API в формате RFC3339. На странице подписки также отображается время окончания.

## Сортировка и фильтры

По умолчанию сначала показываются новые пользователи. В меню доступны варианты **Сначала старые**, **По имени** и **По последнему подключению**. Сортировка работает вместе с поиском по имени/Telegram ID, фильтром статуса и пагинацией. Параметры сохраняются в URL и восстанавливаются после перезагрузки страницы.
