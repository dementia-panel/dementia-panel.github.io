# Введение

dementia — панель для управления собственной VPN-инфраструктурой AmneziaWG. Установка серверов, доступ пользователей, ключи устройств и подписки объединены в одном рабочем пространстве.

## Из чего состоит проект

| Компонент | За что отвечает |
| --- | --- |
| Backend | Хранит настройки, управляет доступом, предоставляет API и устанавливает ноды через SSH. |
| Веб-панель | Интерфейс администратора, доступный по HTTPS. |
| PostgreSQL | Хранит пользователей, подписки, ключи и настройки. |
| Valkey | Redis-совместимое хранилище для ограничения попыток авторизации. |
| Нода | Запускает AmneziaWG и синхронизирует состояние с backend. |

## Порядок запуска

Сначала запустите **backend** вместе с PostgreSQL и Valkey. Установите HTTPS-сертификат, затем запустите **веб-панель**. Оба компонента включены в один Compose-файл установки.

[Перейти к установке →](./installation)

## Управление доступом

**План подписки** — переиспользуемый список серверов. Назначьте его пользователю и настройте срок действия и состояние доступа.

Каждое **устройство** получает отдельные ключи на назначенных серверах и свою ссылку подписки. Добавление устройства сохраняет существующие.

[Пользователи и устройства →](./users)

## Интеграции

Внешние сервисы используют именованный API-ключ, который можно отозвать. В справочник входят только методы для таких ключей, с примерами запросов, ответов и описанием полей.

[Открыть справочник API →](/ru/api/)
